# 🎨 مستندات گرافیکی انجمن علمی مهندسی کامپیوتر دانشگاه صنعتی اصفهان (CESSA)

این مخزن شامل آرشیو طراحی‌های گرافیکی، لوگوها، گواهی‌نامه‌ها، پوسترها و فونت‌های مورد استفاده در فعالیت‌های انجمن علمی مهندسی کامپیوتر دانشگاه صنعتی اصفهان است.

هدف از این مخزن، سامان‌دهی و سهولت دسترسی به فایل‌های گرافیکی برای استفاده مجدد و حفظ هویت بصری انجمن می‌باشد.


## 📁 ساختار پوشه‌ها


    ├── certificate # گواهی‌نامه‌های طراحی‌شده برای رویدادها
    ├── fonts # فونت‌های استفاده‌شده در طراحی‌ها
    ├── logos # لوگوهای داخلی، دانشگاه، مسابقات و حامیان
    │   ├── local
    │   └── sponsers
    ├── posters # پوسترهای طراحی‌شده برای رویدادهای مختلف
    └── ui-ux # فایل‌های رابط کاربری و تجربه کاربری (در صورت وجود)




## 🛠️ نحوه استفاده

- فایل‌های `.ai` را با **Adobe Illustrator** و فایل‌های `.fig` را با **Figma** یا **Xfig** باز کنید.
- پیش از باز کردن فایل‌ها، فونت‌های موجود در پوشه‌ی `fonts` را نصب نمایید تا طراحی‌ها به‌درستی نمایش داده شوند.
- برای حفظ یکپارچگی بصری، از فونت‌های **تحریر** و **کلمه (نسخه Eco)** استفاده نمایید.

---

## 📌 نکات مهم

- در صورت افزودن فایل جدید:
  - آن را در پوشه‌ی مناسب قرار دهید.
  - از نام‌گذاری مشخص و معنادار استفاده کنید.
- اگر از فونت خاصی استفاده شده، حتماً آن را به پوشه‌ی `fonts/` اضافه نمایید.
- لوگوهای مربوط به رویدادها، حامیان و دانشگاه در مسیرهای مشخص قرار دارند.
